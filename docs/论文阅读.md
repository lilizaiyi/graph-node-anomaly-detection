# 参考论文与方法选择

核验日期：2026-10-29。仅以下官方页面和正式论文作为当前依据。

## 首选：DECLARE（IJCAI 2025）

Nannan Wu, Hongdou Dong, Wenjun Wang, Yiming Zhao.
Dual Encoder Contrastive Learning with Augmented Views for Graph Anomaly Detection.
IJCAI 2025, 3480–3488. DOI: 10.24963/ijcai.2025/387.

- 官方入口：https://ijcai.org/proceedings/2025/387
- 正式论文：https://www.ijcai.org/proceedings/2025/0387.pdf
- 作者单位包含天津大学智能与计算学部，任务是属性图节点异常检测。

方法阅读重点：GCN 与 NodeFormer 双编码器、PPR 扩散视图、节点与子图对比、结构和属性重构、最终异常分数。
论文使用 Cora、Citeseer 等基准；同名数据不等于相同异常标签，复现前必须核对数据版本和异常注入协议。
本次未确认可用的作者官方代码仓库，不能把其他仓库当成作者代码。

## 相关但不优先：HOSCL（IJCAI 2024）

Anomaly Subgraph Detection through High-Order Sampling Contrastive Learning.
正式论文：https://www.ijcai.org/proceedings/2024/0261.pdf

研究对象是异常子图，与当前节点级任务不同。适合作为背景阅读，不直接混用任务和评价结果。

## 从基础模型到论文复现

当前代码仅实现 GCN 双重构起步基线。完整 DECLARE 还需要：

1. 核对原文公式、采样过程、具体超参数及缺失的实现细节。
2. 实现 PPR 视图、带重启随机游走子图采样和目标节点属性遮蔽。
3. 接入 NodeFormer 编码器，保留来源与许可证。
4. 实现节点-子图正负对、视图内与视图间损失。
5. 核对重构目标、两编码器训练目标、最终分数及重复采样评价。
6. 在相同数据版本和协议下做复现与消融，并记录与原文的差异。
