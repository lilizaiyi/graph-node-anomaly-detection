# 可执行研究方案

## 当前问题

图结构信息与属性重构是否提供互补的异常检测信号？先完成基础实验，再决定是否扩展到 DECLARE 的对比学习模块。

## 已完成基础设施

- 统一数据接口与合法性检查。
- 属性 PCA、邻域残差、分数融合三项基础对照。
- GCN 双重构与属性/结构重构目标消融代码。
- ROC-AUC、AP、逐节点分数、训练损失、配置与环境记录。
- 固定数据种子与训练种子分离，避免将不同合成图的变化误称为训练稳定性。

## 接下来按顺序完成

1. 选一个有明确来源的节点异常检测数据版本，登记下载链接、许可证、异常标签来源和文件校验值。
2. 转为 NPZ 并验证节点对齐；不要直接把普通节点类别当成异常标签。
3. 跑三个基础对照，检查异常分数和标签方向。
4. 安装 PyTorch 后跑 GCN 三组目标，每组 3 个种子，保留全部结果。
5. 核查损失曲线和分数分布，若修改训练规则，记录修改并公平重跑相关方法。
6. 若时间充足，再开展完整 DECLARE 复现；若时间有限，保留基线研究定位并补足真实数据与分析。
7. 加第二个数据集；对最高分误报和漏报节点做局部案例分析。
8. 写 4–6 页报告，所有未完成实验留空，不填论文数字冒充自己的结果。

## 研究边界

当前只有合成流程检查，不是完成后的结课实验。GCN 教学实现也不等于 DECLARE。
合成数据上的异常由已知规则生成，会偏向某些检测方法，不能据此证明真实场景优势。
重构目标消融只说明目标项的作用，不足以证明去掉结构或属性输入的效果。
