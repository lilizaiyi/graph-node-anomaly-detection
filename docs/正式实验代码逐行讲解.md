# 图节点异常检测代码逐行讲解

这份讲解对应在 CMD 里运行的两条 Python 命令。第一条准备 Books 和 Disney 数据，第二条训练模型、计算指标并保存结果。编号对应当前源码中的行号。连续几行组成同一个语句时放在一起讲，空行只用于分隔代码。

## 方法和数据

图卷积用对称归一化邻接矩阵聚合邻居特征。双重构用一个 GCN 编码器和两个解码器，分别还原节点属性和连边。实验比较邻居聚合、结构重构训练和结构评分对异常排序的影响。代码使用 PyTorch 和 NumPy，数据为公开的 Books 和 Disney 共购图。 [GCN](https://arxiv.org/abs/1609.02907) · [DOMINANT](https://doi.org/10.1137/1.9781611975673.67) · [DECLARE](https://ijcai.org/proceedings/2025/387) · [PyGOD 数据](https://github.com/pygod-team/data)

## 先看程序怎么走

```text
公开数据压缩包
    → prepare_benchmarks.py 转换和校验
    → NPZ 保存 x、a、y
    → run_course_experiment.py 读取配置和数据
    → 基线直接打分，或训练 MLP / GCN 并生成分数
    → 对照 y 计算 AUROC、AP 和前十名命中率
    → 结果目录保存指标、逐节点排名、损失和权重
```

先记住 `N` 是节点数，`F` 是属性维数。例如 Books 的 `N = 1418`，`F = 21`。

| 变量 | 形状 | 含义 |
|---|---|---|
| `x` | `[N, F]` | 每行是一个节点的属性向量 |
| `a` | `[N, N]` | `a[i, j] = 1` 表示节点 i 和 j 有边 |
| `y` | `[N]` | 每个节点的异常标注，0 为正常，1 为异常 |
| `z` | `[N, 8]` | 训练后给每个节点得到的 8 维表示 |
| `x_hat` | `[N, F]` | 解码器还原出来的属性，和目标属性比较 |
| `anomaly_score` | `[N]` | 每个节点一个分数，数值越大，排序越靠前 |

建议第一次先看第 5 部分的模型和训练，再回来看第 1、2 部分的数据。模型的连边训练目标来自 `a`。每个节点是否异常的标签 `y` 在模型评分后用来核对排序。

| 13 | 当相邻分数不相等时，当前同分组结束。`ends` 记录所有组的结束位置，并补上最后一组。 |
| 14 | 对标签累加，在每个同分组末尾得到截至该阈值的真阳性数 TP。前面补 0 代表尚未选择节点。 |
| 15 | 截至同分组末尾的总人数减去 TP，得到误判为异常的正常节点数 FP，也在开头补 0。 |
| 16 | 用 TP 除以异常总数得到真阳性率 TPR，用 FP 除以正常总数得到假阳性率 FPR。 |
| 17 | 沿 FPR 方向累加梯形面积，得到 ROC 曲线下面积 AUROC。 |
| 18 | 每个非空阈值上，用 TP 除以选中的总数 TP + FP，得精确率。 |
| 19 | 当阈值下降时，召回率提高了多少就给该点的精确率相应权重。把所有增量乘精确率相加，得到 AP。 |
| 20 | 返回指标字典，转为普通浮点数方便写入 CSV。 |

举个四节点例子。按分数从高到低的标签是 `1, 0, 1, 0`。真正异常的两个节点排第 1 和第 3 名。召回每遇到一个异常就增加 0.5，两个位置处的精确率分别是 `1/1` 和 `2/3`，所以 AP 为 `0.5 × 1 + 0.5 × (2/3) ≈ 0.8333`。若几个节点同分，指标函数把它们作为一个阈值同时处理。
